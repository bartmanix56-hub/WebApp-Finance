Guide d'utilisation

Vue d'ensemble

Votre tableau de bord principal qui affiche :

  • Vos comptes bancaires : cliquez sur un montant pour le modifier
  • Budget mensuel : revenus à gauche, dépenses fixes à droite
  • Dépenses variables : restaurants, sorties, shopping, etc.
Astuce : Double-cliquez sur un nom de catégorie pour le renommer, simple clic sur un montant pour le modifier.

Navigation mensuelle

En haut de l'écran, vous pouvez :

  • Changer de mois avec les flèches ← →
  • Voir le budget restant en temps réel
  • Budget quotidien : combien vous pouvez dépenser par jour jusqu'à la fin du mois
Les données sont automatiquement sauvegardées toutes les 500ms dans votre navigateur. Pas besoin de cliquer sur "Enregistrer".

Transactions récurrentes

Lors de l'ajout d'une transaction, cochez "Récurrent chaque mois" pour :

  • Loyer, abonnements, salaire → ajoutés automatiquement
  • Restaurant, shopping → ne pas cocher (dépenses ponctuelles)
Magie : Quand vous passez au mois suivant, toutes les transactions récurrentes sont copiées automatiquement. Vous n'avez à ajouter que les dépenses ponctuelles !

Icônes personnalisées

Chaque transaction peut avoir une icône :

  • Détection automatique : si vous tapez "Spotify", l'icône musique s'affiche
  • Sélection manuelle : 33 icônes disponibles dans le modal d'ajout
  • Navigation visuelle : identifiez vos dépenses en un coup d'œil

Graphiques

L'onglet "Graphiques" affiche :

  • Camembert : où part votre argent (par catégorie)
  • Histogramme : revenus vs dépenses fixes vs variables
Les graphiques se mettent à jour en temps réel quand vous modifiez vos données.

Objectifs d'épargne

Définissez des objectifs à atteindre :

  • Vacances, nouvelle voiture, fonds d'urgence...
  • Suivez votre progression avec une barre visuelle
  • Mettez à jour le montant actuel manuellement

Report de solde

Si votre budget est positif en fin de mois :

  • Le surplus est automatiquement reporté au mois suivant
  • Votre budget du mois prochain = revenus - dépenses + report
  • Suivez votre enrichissement sur le long terme

Mode clair / sombre

Changez le thème selon vos préférences :

  • Cliquez sur l'icône ☀️/🌙 en haut à droite
  • Votre choix est sauvegardé entre les sessions

Raccourcis clavier

Alt + ← Mois précédent
Alt + → Mois suivant
Échap Fermer modal

Export des données

Deux formats disponibles en haut à droite :

  • JSON : pour backup ou ré-import
  • CSV : pour ouvrir dans Excel / Google Sheets
Conseils d'utilisation :
  1. Commencez par ajouter vos revenus mensuels (salaire, APL...)
  2. Ajoutez vos dépenses fixes récurrentes (loyer, abonnements...)
  3. Au fil du mois, ajoutez vos dépenses variables (sorties, shopping...)
  4. Consultez régulièrement votre "Budget restant" et "Par jour"
  5. Définissez des objectifs d'épargne pour vous motiver

👋 Bienvenue sur Budget Personnel

Une application simple et puissante pour gérer votre budget mensuel. Voici comment commencer :

Étape 1 : Vos revenus

Ajoutez vos revenus mensuels (salaire, allocations...). Cochez "Récurrent" pour qu'ils apparaissent automatiquement chaque mois.

Étape 2 : Dépenses fixes

Loyer, Internet, abonnements... Cochez "Récurrent" pour ne pas les ressaisir chaque mois.

Étape 3 : Dépenses variables

Restaurant, sorties, shopping... Au fil du mois, ajoutez vos dépenses ponctuelles.

Le reste se fait tout seul !

Budget restant, graphiques, objectifs d'épargne, report mensuel... Tout est automatique. Consultez le Guide dans la barre latérale pour en savoir plus.
